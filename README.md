# Fortune Cookie Funnies for Engineers

> A junior will ask why. The answer hides in a 2019 commit message: 'fix stuff'.

**Length:** 78 characters (limit: 120)

## Why it should win

- **A real fortune cookie for an engineer:** it opens like a prophecy ("A junior will ask why") and the twist comes straight from the engineer's world — a commit message.
- **A genuine punchline on first read:** `'fix stuff'` is the laziest commit message every engineer has written or inherited, and it lands the moment you read it.
- **Fresh, not a mug line:** the specific detail — a 2019 commit message saying exactly `'fix stuff'` — is a scene nobody has printed on a sticker.
- **Tight, funniest word last:** 78 characters, every word earns its place, and the joke's payoff is the final word the reader sees.

`main.py` (Python 3.13, stdlib only, no network, deterministic) builds the fortune from named parts and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default).
